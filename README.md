# ShopCart

A generic, multi-tenant ordering & billing platform — built to fix a real problem
(manual provision-shop orders getting billed wrong) but designed to work for
**any small business**: provision stores, pharmacies, laundry services, etc.

## How it solves the original problem

- You (customer) pick **exact quantity** from a digital catalog — no verbal
  "half kg" that becomes "1 kg" on the shop's side.
- The **system computes the price**, not a person. Total is always
  `quantity × price` — no manual billing math, no room for error.
- Every order **snapshots the price at order time** (`unit_price_snapshot`),
  so even if the shop changes prices tomorrow, yesterday's bill stays exactly
  what it was — non-negotiable trust guarantee.

## Architecture

```
shopcart/
├── backend/     FastAPI + PostgreSQL (multi-tenant: Business → Product → Order → OrderItem)
└── frontend/    React (Vite) — customer catalog/cart + shop owner dashboard
```

**Multi-tenancy model:** one shared set of tables for every business type
(`Business.type` = provision / pharmacy / laundry / ...). Vertical-specific
fields (e.g., pharmacy's "requires prescription", laundry's "turnaround
hours") are stored in a flexible `Product.attributes` JSONB column — no new
tables needed per business type.

## Key features already built
- Signup/login (customer & shop_owner roles), JWT auth
- Shop owner creates a Business, adds/edits/soft-deletes products
- **Bulk import** — upload an Excel/CSV rate list, auto-maps columns
  (name/unit/price), extra columns become flexible attributes
- Automatic **price history** log on every price change
- Customer browses catalog, builds cart (supports fractional qty like 0.5 kg),
  places order
- Order price is **snapshotted** at order time (bug-proof billing)
- Shop dashboard: manage catalog, move orders through
  placed → confirmed → packing → ready → dispatched → delivered

## Local setup

### 1. Database (Neon — free Postgres)
1. Go to https://neon.tech → sign up free → create a project.
2. Copy the connection string (looks like
   `postgresql://user:pass@ep-xxx.neon.tech/dbname?sslmode=require`).

### 2. Backend
```bash
cd backend
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env           # then paste your Neon DATABASE_URL + a random JWT_SECRET
uvicorn app.main:app --reload  # http://localhost:8000
```
Visit http://localhost:8000/docs for interactive API docs (auto-generated by FastAPI).

Tables are auto-created on first run (`Base.metadata.create_all`). Fine for
learning; switch to Alembic migrations once the schema stabilizes.

### 3. Frontend
```bash
cd frontend
npm install
cp .env.example .env    # VITE_API_URL=http://localhost:8000
npm run dev              # http://localhost:5173
```

### 4. Try it end to end
1. Sign up as **shop_owner** → you'll be prompted to create your Business
   (e.g. "My Provisions Store", type=provision).
2. In the Dashboard, add a few products manually, or upload a CSV/Excel with
   columns like `Name, Unit, Price` to bulk-import.
3. Sign up a **second account** as **customer** (use a different phone
   number/browser tab).
4. Browse Shops → open your store → add items to cart (try 0.5 kg) → Place
   Order.
5. Back in the shop_owner account → Dashboard → see the order, move its
   status.

## Deploying (free tier)

### Database → Neon
Already done above if you followed local setup — same connection string works in production.

### Backend → Render
1. Push this repo to GitHub.
2. On https://render.com → New → Blueprint → point to your repo (uses the
   included `render.yaml`).
3. Set environment variable `DATABASE_URL` to your Neon connection string
   (Render will auto-generate `JWT_SECRET`).
4. Deploy — Render gives you a URL like `https://shopcart-api.onrender.com`.

> Free tier note: Render's free web services spin down after ~15 min of
> inactivity and take ~30-50s to wake up on the next request. Fine for
> learning/demo; upgrade to a paid instance ($7/mo) once you have real users.

### Frontend → Render Static Site (or Vercel/Netlify)
1. New → Static Site → same repo, root directory `frontend`.
2. Build command: `npm install && npm run build`, publish directory: `dist`.
3. Environment variable: `VITE_API_URL` = your deployed backend URL.
